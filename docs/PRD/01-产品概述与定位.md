## 1. 公司战略定位

### 1.1 核心定位

> **南京流苏智慧信息技术有限公司 = AI 智能体驱动的工业安全底座服务商**

不仅仅是"安全生产信息化系统提供商"——我们为企业提供的不是传统的信息化软件，而是一套**基于 AI 智能体架构的工业安全管理平台**，以及围绕该平台构建的**可复用、可编排的 Skill 生态**。

### 1.2 与传统信息化系统的根本区别

| 维度 | 传统信息化系统 | 南京流苏 AI 智能体平台 |
|------|---------------|----------------------|
| **架构** | 单体应用/微服务，功能固化 | AI 智能体底座 + Skill 插件化编排 |
| **交互** | 菜单→页面→按钮→弹窗，人找系统 | 对话式 + 自动感知，系统找人 |
| **数据** | 录入→存储→报表，数据沉睡 | 自动采集→AI 分析→主动预警→自动上报 |
| **迭代** | 改需求要改代码，版本发布慢 | 新需求 = 新 Skill，热插拔，独立迭代 |
| **集成** | 对接每个政府平台单独开发 | 统一合规中台，Skill 按需对接 |
| **智能** | 仅规则引擎，无 AI 能力 | LLM + RAG + 视觉 AI + 知识图谱 融合 |
| **部署** | 私有化部署为主，维护成本高 | SaaS + 可选离线部署，统一运维 |

### 1.3 核心原则

1. **AI 原生** — 所有功能以 AI 智能体为最小单元构建，而非以"菜单/页面"为单位
2. **Skill 即产品** — 每个业务能力封装为独立 Skill，像乐高积木一样可组合、可复用、可售卖
3. **数据驱动** — 不是靠人工填表，而是 IoT/视频/设备实时数据自动驱动
4. **合规自动化** — 让"向政府上报数据"这件事从人工变成自动
5. **租户隔离** — 每个企业数据物理隔离，支持 SaaS 和离线部署两种模式

## 3. 商业闭环全链路

```
官网宣传 (吸引客户)
    │
    ▼
企业入驻申请 (填写信息 + 勾选关注的 Skill)
    │
    ▼
我司超级管理员审核 (电话确认 + 资质核实)
    │
    ▼
审核通过 → 创建企业租户 → 签发 License → 开通 Skill 权限
    │
    ▼
企业管理员登录企业端
    ├── 配置对接 (传感器/视频/人员数据)
    ├── 启用 Skill
    └── 开始使用：AI 智能体自动运行
    │
    ▼
可选：离线部署 (私有化/信创环境)
    └── 数据不出企业，定期同步配置
```

## 5. 关键业务指标 (KPI)

| 指标 | 目标 | 衡量方式 |
|------|------|---------|

| Skill 激活率 | 入驻企业平均激活 ≥ 3 个 Skill | 平台统计 |

| 数据自动采集占比 | ≥ 70% | 自动采集 / 总数据量 |
| 系统可用性 | ≥ 99.9% | SaaS 平台监控 |
