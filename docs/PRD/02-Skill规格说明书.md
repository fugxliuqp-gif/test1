## 通用 Skill 设计模式

每个 Skill 遵循统一架构：

```
Skill = { 感知器 perceive() + 分析器 analyze() + 执行器 execute() + 反馈器 feedback() }
```

**Skill 生命周期**：

```
注册 (YAML 声明) → 配置 (企业自定义参数) → 激活 (License 控制) → 运行 (Agent 调度) → 停用/升级
```

**Skill 交互方式**：
1. **自动运行** — Agent 按计划/事件触发，无需人工介入
2. **对话交互** — 企业用户通过自然语言与 Skill 交互
3. **混合模式** — 自动运行 + 关键节点人工确认

**Skill 间编排**：Skill 的输出可作为另一 Skill 的输入，形成自动化链路

## Skill-A：数字资产自动化维护管理

### 一句话描述

让企业的文件和数据"活"起来——自动扫描、识别、解析、入库，构建企业知识资产库。

### 解决的问题

- 企业积累了海量 Excel/Word/PDF，但数据沉睡，无法被检索和利用
- 设备台账、操作规程、历史报告等分散在个人电脑/文件服务器上
- 员工离职导致"数据跟着人走"
- 同一数据在不同文件中不一致，无人发现

### 核心能力

| 能力 | 说明 | 技术方案 |
|------|------|---------|
| **文件自动感知** | 监控指定目录/上传入口的文件变化 | inotify + 定时扫描 |
| **格式自动识别** | 自动识别 Excel/Word/PDF/图片/CSV | MIME 检测 + openpyxl/python-docx/pdfplumber |
| **内容结构化** | 提取表格、段落、关键字段，转为统一格式 | 解析引擎 + LLM 辅助 |
| **冲突检测** | 比对已有数据，发现不一致 | 字段级哈希比对 |
| **智能分类** | 按内容自动归入分类树 | RAG + 语义分类 |
| **向量化入库** | 转为向量存入知识库，支持语义检索 | embedding + Milvus |
| **变更日志** | 记录每一次数据变更，可追溯 | 审计日志表 |

### 典型场景

```
场景 1：设备台账自动入库
企业上传"设备台账 2026Q1.xlsx"
  → Skill-A 自动识别格式、解析数据
  → 比对已有台账，发现 3 台设备已报废、5 台新设备
  → 自动更新台账 → 推送变更报告给管理员
  → 管理员确认 → 入库

场景 2：操作规程 RAG 化
企业把"XX 车间操作规程.pdf"拖入系统
  → Skill-A 解析全文 → 提取 47 条操作步骤
  → 向量化 → 存入 RAG 知识库
  → 以后工人问"反应釜升温操作步骤" → LLM 自动检索回答

场景 3：历史数据挖掘
企业有 3 年的隐患记录 Excel
  → Skill-A 批量导入 → 分析隐患类型分布
  → 发现"电气线路"类隐患占比 35%，呈上升趋势
  → 自动生成分析报告 → 推送管理层
```

### 输入 / 输出

| 项目 | 说明 |
|------|------|
| **输入** | 文件 (Excel/Word/PDF/CSV/图片)、目录路径、API 上传 |
| **输出** | 结构化数据、向量化数据、变更日志、分析报告 |
| **配置参数** | 扫描路径、分类规则、冲突策略(自动/人工)、入库策略 |

## Skill-B：政府合规自动上报智能体

### 一句话描述

让企业从"每天填表上报"中彻底解放——系统自动从企业内部数据提取、组装、上传到各政府监管平台。

### 解决的问题

- 企业需要分别对接应急管理部、环保局、人社局、消防等多家监管部门
- 每个平台格式不同、填报周期不同、字段口径不同
- 安全管理人员 30%+ 的时间花在填表上
- 漏报/迟报面临罚款和处罚

### 核心能力

| 能力 | 说明 | 对接平台 |
|------|------|---------|
| **数据自动提取** | 从企业数据库/IoT/文件中提取合规所需数据 | 内部数据源 |
| **格式自动转换** | 按各监管平台要求组装数据格式 | 应急管理部 / 环保局 / 人社局 / 消防 |
| **自动填报** | 模拟登录 + API 对接，自动提交 | 各政府监管平台 |
| **合规检查** | 填报前自动检查数据完整性、时效性、合理范围 | — |
| **失败重试** | 上报失败自动重试 3 次，仍失败通知人工 | — |
| **合规证明** | 自动生成上报截图/回执/存档 | — |
| **日历调度** | 支持每日/每周/每月/季度/年度的定时上报 | 自定义规则 |

### 对接平台清单 (初期)

| 监管领域 | 平台/文件 | 上报内容 | 频率 |
|---------|----------|---------|------|
| **安全生产** | 应急管理部 — 风险监测预警系统 | 重大危险源监测数据、隐患排查数据 | 实时/每日 |
| **安全生产** | 应急管理部 — 双重预防机制数字化平台 | 风险点分布、隐患排查记录、整改闭环 | 每月 |
| **安全生产** | 省应急厅 — 安全生产监管平台 | 企业安全基础信息、培训记录、事故统计 | 季度 |
| **环保** | 生态环境部 — 重点排污单位自动监控 | 废气/废水排放数据、固废处置记录 | 实时/每月 |
| **环保** | 省环保厅 — 企业环境信用评价系统 | 环境监测数据、排污许可执行 | 每年 |
| **劳保** | 人社局 — 职业健康管理系统 | 职业健康体检、劳保用品发放 | 年度 |
| **消防** | 消防救援总队 — 社会消防管理平台 | 消防设施状态、巡检记录 | 每月 |

### 典型场景

```
场景 1：月度安全数据上报
每月 5 日上午 10:00 → Skill-B 自动触发
  → 从企业数据库提取: 隐患数量/整改率/重大危险源状态/培训人次
  → 按应急管理部 5 号文格式组装 JSON
  → 登录安全监管平台 → 自动填报
  → 截图存档 → 推送"本月合规上报已完成"给安全管理员

场景 2：环保超标自动说明
环保传感器检测到 SO₂ 排放瞬时超标
  → Skill-C (监控) 触发告警
  → Skill-B 自动接收告警数据
  → 生成超标说明报告
  → 推送到环保局自动监控平台
  → 同时通知环保管理员："已自动提交超标说明，请关注后续处理"

场景 3：年度合规体检
每年 1 月 → Skill-B 自动执行年度合规自查
  → 遍历所有合规检查项（127 项）
  → 标记通过/未通过/待补充
  → 生成年度合规体检报告
  → 推送管理层 + 建议整改计划
```

### 输入 / 输出

| 项目 | 说明 |
|------|------|
| **输入** | 企业内部数据 (DB/IoT/API)、调度规则 (cron) |
| **输出** | 上报结果 (成功/失败)、合规证明 (截图/回执)、合规报告 |
| **配置参数** | 对接平台列表、上报频率、失败策略、通知人 |

## Skill-C：重大危险源 & 视频 AI 监控智能体

### 一句话描述

24 小时不眨眼的工业安全哨兵——融合 IoT 传感器 + 视频 AI + 设备数据分析，实时感知风险、提前预警。

### 解决的问题

- 重大危险源(储罐/反应釜/管道)靠人工定时巡检，盲区大
- 监控画面海量但无人看，事后查视频已成常态
- 传感器报警阈值固定，无法识别趋势性风险
- 各类报警分散在不同系统，无统一研判

### 核心能力

| 能力 | 说明 | 技术方案 |
|------|------|---------|
| **IoT 数据接入** | 接入液位、温度、压力、可燃气体、振动等传感器 | MQTT / Modbus / OPC UA |
| **视频 AI 分析** | 实时分析监控画面，识别安全违规 | YOLO / 边缘推理 |
| **多源融合研判** | 结合多传感器 + 视频 + 设备数据综合判断 | 规则引擎 + AI 模型 |
| **趋势预测** | 基于历史数据预测未来状态，提前预警 | 时序预测模型 |
| **分级告警** | 低/中/高/紧急四级，自动匹配处置策略 | 告警分级规则 |
| **自动联动** | 高风险自动联动应急设备(喷淋/关阀/广播) | IoT 反向控制 |
| **事件回放** | 告警前后 5 分钟视频自动保存，支持回放 | 视频环形缓冲区 |

### 视频 AI 分析场景 (初期)

| 检测类型 | 识别内容 | 告警级别 |
|---------|---------|---------|
| **安全防护** | 未戴安全帽 | 中 |
| **安全防护** | 未穿防护服/反光衣 | 中 |
| **行为检测** | 人员倒地/晕厥 | 高 |
| **行为检测** | 吸烟/明火 | 高 |
| **区域管控** | 闯入危险区域/电子围栏 | 高 |
| **设备状态** | 跑冒滴漏/烟雾 | 紧急 |
| **设备状态** | 作业区域违规操作 | 中 |
| **人员管理** | 脱岗/睡岗 | 中 |
| **车辆管理** | 违规停车/堵塞消防通道 | 低 |

### 典型场景

```
场景 1：液氨储罐预警
液氨储罐压力传感器数据实时接入 Skill-C
  → AI 分析趋势，预测 15 分钟后将达阈值
  → 触发"中风险"告警 → 推送值班人员
  → 同时联动：开启储罐区喷淋系统预冷
  → 事件记录存档

场景 2：视频抓拍违章
监控画面拍到某工人未戴安全帽进入生产区
  → Skill-C 视频 AI 识别 → 抓拍人脸
  → 比对人员库 → 匹配到"张某某，机修车间"
  → 推送违章记录给车间主管
  → 自动触发 Skill-D：给张某某推送安全培训任务

场景 3：多源融合研判
反应釜温度异常升高 + 压力同步上升 + 视频可见蒸汽
  → Skill-C 综合研判：高风险，可能泄漏
  → 自动关断进料阀 + 启动紧急排空 + 广播疏散
  → 同时通知安全总监和值班工程师
  → 全过程自动记录，供事后分析
```

### 输入 / 输出

| 项目 | 说明 |
|------|------|
| **输入** | IoT 传感器数据流、RTSP 视频流、设备 DCS 数据 |
| **输出** | 告警事件、联动指令、分析报告、事件回放 |
| **配置参数** | 传感器阈值、视频分析区域、告警级别规则、联动策略 |

## Skill-D：企业内部管控中台

### 一句话描述

把企业写在纸上的安全管理制度变成自动运行的规则引擎——双控、特殊作业、危化品、承包商、培训全链路数字化。

### 解决的问题

- 双重预防机制"纸面化"——制度写了一大本，执行是两张皮
- 特殊作业票审批靠跑腿，效率低且易造假
- 危化品从采购到废弃全链条追踪困难
- 承包商管理凭经验，缺乏量化考核
- 安全培训"签到即合格"，效果无法衡量

### 核心能力

| 模块 | 能力 | 说明 |
|------|------|------|
| **风险分级管控** | 风险点识别 | 支持 LEC/LS 等多种评价方法 |
|  | 风险四色图 | 红/橙/黄/蓝可视化 |
|  | 措施自动推送 | 根据风险等级自动匹配管控措施 |
| **隐患排查治理** | 任务自动派发 | 按周期/区域/岗位自动生成巡查任务 |
|  | 拍照+AI 识别 | 隐患拍照上传，AI 辅助分类和定级 |
|  | 整改闭环 | 发现→派发→整改→验收→归档 |
|  | 超时督办 | 超期未整改自动推送上级 |
| **特殊作业管理** | 作业票电子化 | 动火/受限空间/高处/吊装/临时用电/盲板抽堵/断路/挖掘 8 大作业 |
|  | AI 辅助审核 | 作业票内容完整性检查、风险匹配 |
|  | 视频旁站 | 作业过程视频录制，AI 识别违规操作 |
|  | 自动归档 | 作业完成后自动形成完整档案 |
| **危化品管理** | 全链条追踪 | 采购→入库→领用→使用→废弃→处置 |
|  | RFID 自动识别 | 出入库自动扫码登记 |
|  | 库存预警 | 库存低于安全水位自动提醒补货 |
|  | 过期提醒 | 危化品到期前自动提醒处置 |
| **承包商管理** | 资质自动核验 | 安全许可证/特种作业证自动比对 |
|  | 现场作业监控 | 作业过程全程记录 |
|  | 考核评分 | 完工后自动生成评分 |
| **安全培训** | 自动推送学习 | 根据岗位/风险推送培训内容 |
|  | AI 组卷 | 根据培训内容自动生成考题 |
|  | 自动阅卷 | 客观题自动批改，主观题 AI 辅助 |
|  | 证书管理 | 培训合格证/特种作业证到期提醒 |

### 典型场景

```
场景 1：隐患巡查闭环
系统自动派发"本周机修车间巡查任务"给陈主管
  → 陈主管巡查发现"电机接地线脱落"
  → 手机拍照上传 → AI 识别为"电气隐患/一般风险"
  → 自动派发整改任务给维修班组
  → 维修完成 → 拍照验收 → 归档
  → 全过程 2 小时，过去需要 2 天

场景 2：动火作业快速审批
操作工提交动火作业申请
  → AI 审核：作业区域风险匹配 ✓ / 监护人已指定 ✓ / 应急措施已勾选 ✓
  → 自动通过基础审核 → 推送安全主管
  → 安全主管手机上确认 → 动火票生效
  → 全程 8 分钟，过去需要跑 3 个办公室

场景 3：危化品全链条追踪
液氨入库 → RFID 自动记录
  → 生产车间领用 500kg → 扫码出库
  → 使用过程中传感器监测液氨消耗
  → 库存低于 200kg 自动提醒采购
  → 过期前 30 天自动提醒处置
  → 每月自动生成危化品使用报告
```

### 输入 / 输出

| 项目 | 说明 |
|------|------|
| **输入** | 巡查数据、作业申请、传感器数据、RFID 数据 |
| **输出** | 管控记录、预警通知、统计分析报表、合规档案 |
| **配置参数** | 巡查周期、风险评级规则、审批流程配置、预警阈值 |
