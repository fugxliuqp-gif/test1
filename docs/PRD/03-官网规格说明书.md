## 1. 官网定位

**三重使命**：
1. **品牌塑造** — 传递"AI 智能体驱动的工业安全底座服务商"的新定位
2. **获客转化** — 通过 Skill 展示吸引企业用户 → 引导入驻申请
3. **信任建设** — 展示政策合规能力、技术实力、客户案例

### 3.4 申请入驻表单

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 企业名称 | 文本 | ✅ | 全称 |
| 统一社会信用代码 | 文本 | ✅ | 9 位校验 |
| 所属行业 | 下拉选择 | ✅ | 化工/制药/钢铁/食品/电力/其他 |
| 企业规模 | 下拉选择 | ✅ | 50人以下 / 50-200人 / 200-500人 / 500-1000人 / 1000人以上 |
| 联系人姓名 | 文本 | ✅ | |
| 联系人手机号 | 手机号 | ✅ | 11 位 |
| 联系人邮箱 | 邮箱 | ✅ | |
| 关注 Skill | 多选复选框 | ✅ | Skill-A/B/C/D + 自定义填写 |
| 需求描述 | 多行文本 | ❌ | 选填，描述具体需求场景 |
| 当前使用系统 | 多行文本 | ❌ | 选填，描述当前信息化状况 |

**提交后流程**：
```
提交成功 → 弹窗提示"已收到申请，我司将在 1-2 个工作日内联系您"
  → 异步通知我司超级管理员
  → 申请记录写入数据库 (状态: pending)
```

## 4. 技术方案

### 4.1 技术栈

| 层面 | 技术 | 说明 |
|------|------|------|
| **前端框架** | React + TypeScript + Vite | 保持现有技术栈 |
| **UI 组件** | Ant Design 6 + Tailwind CSS | 成熟的企业级组件 |
| **状态管理** | React Query (数据) + Zustand (全局) | 与 ai-admin-demo 一致 |
| **路由** | React Router v6 | Hash 或 Browser 路由 |
| **构建** | Vite | 快速开发体验 |
| **后端框架** | FastAPI + Python 3.11+ | 异步高性能 |
| **ORM** | SQLAlchemy 2.0 async | 成熟的企业级 ORM |
| **数据库** | PostgreSQL 15（生产） / SQLite（开发） | 可按阶段迁移 |
| **鉴权** | JWT（官网 admin）+ 后续多租户认证 | |
| **存储** | MinIO / 本地文件系统 | 图片等静态资源 |
| **部署** | Nginx + Docker | 与现有腾讯云兼容 |

### 4.2 后端 API 设计

#### 公开接口 (无需认证)

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/cms/banners` | 首页 Banner 列表 |
| GET | `/api/cms/skills` | Skill 列表 (含详情) |
| GET | `/api/cms/skills/{id}` | Skill 详情 |
| GET | `/api/cms/policies` | 政策合规列表 |
| GET | `/api/cms/contact` | 联系方式 |
| GET | `/api/cms/stats` | 统计数据 (覆盖企业数/上报成功率等) |
| GET | `/api/cms/stories` | 案例列表 |

#### 入驻申请接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/apply` | 提交入驻申请 |
| GET | `/api/apply/status?code={code}` | 查询申请进度 |

#### 管理接口 (需 super_admin 认证)

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/cms/banners` | 新增 Banner |
| PUT | `/api/cms/banners/{id}` | 编辑 Banner |
| DELETE | `/api/cms/banners/{id}` | 删除 Banner |
| PUT | `/api/cms/skills/{id}` | 编辑 Skill 信息 |
| PUT | `/api/cms/stories` | 编辑案例 |
| GET | `/api/admin/applications` | 入驻申请列表 |
| PUT | `/api/admin/applications/{id}` | 审核入驻申请 (通过/拒绝) |
