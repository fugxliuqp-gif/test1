## 1. 总览：全链路流转

```
官网申请 → 我司超级管理员审核 → 企业租户创建 → License 签发 → 企业管理员激活
```

## 2. 我司超级管理员后台

### 2.1 核心功能

| 模块 | 功能 | 说明 |
|------|------|------|
| **入驻审核** | 申请列表 | 所有待审核/已通过/已拒绝申请 |
|  | 审核操作 | 通过 (自动创建企业租户) / 拒绝 (填写理由) |
|  | 企业详情 | 查看企业提交的信息 |
| **企业管理** | 企业列表 | 所有已入驻企业 |
|  | 企业详情 | 基本信息、License、活跃 Skill、数据用量 |
|  | 编辑企业 | 修改企业信息 (非敏感字段) |
|  | 暂停/恢复 | 暂停企业服务 (数据保留) |
| **License 管理** | License 列表 | 所有企业 License |
|  | 生成 License | 选择企业、类型、有效期 |
|  | 续期 | 延长有效期 |
|  | 吊销 | 即时吊销 (数据冻结) |
| **Skill 管理** | Skill 列表 | 平台所有 Skill |
|  | 企业 Skill 分配 | 为每个企业开通/关闭 Skill |
|  | Skill 版本管理 | 升级/回滚企业使用的 Skill 版本 |
| **平台监控** | 数据看板 | 总企业数、活跃企业、API 调用量 |
|  | 告警 | 异常行为、License 即将到期 |
|  | 日志 | 操作审计日志 |

### 2.2 审核流程

```
申请提交 (status: pending)
    │
    ▼
我司客服电话沟通 (确认需求 + 资质)
    │
    ▼
审核操作
├── 通过 → 自动创建企业租户 + 签发试用 License (30天)
│         → 发送通知邮件/短信给企业联系人
│         → 企业管理员可登录企业端
│
└── 拒绝 → 填写拒绝理由
          → 系统通知申请人
          → 记录到审计日志
```

## 3. 企业端 (SaaS 租户)

### 3.1 企业管理员首次登录

```
接收审核通过通知 (含登录链接 + 初始密码)
    │
    ▼
首次登录 → 强制修改密码
    │
    ▼
引导式配置向导 (首次登录流程)
    ├── Step 1: 完善企业信息 (可选)
    ├── Step 2: 配置管理员/成员
    ├── Step 3: 查看已开通的 Skill
    └── Step 4: 开始使用 (进入 AI 对话主页)
```

### 3.2 企业端核心页面

| 页面 | 功能 | 说明 |
|------|------|------|
| **AI 对话主页** | 自然语言交互 | 与智能体对话，调用 Skill |
| **工作台** | 数据概览 | 今日预警、待处理任务、上报状态 |
| **Skill 面板** | Skill 列表 | 已开通的 Skill，可配置参数 |
| **数据看板** | 统计报表 | 安全数据、上报记录、趋势分析 |
| **成员管理** | 成员 CRUD | 添加/编辑/禁用企业成员 |
| **角色权限** | 角色分配 | 管理员/安全员/操作员 三级 |
| **系统设置** | 对接配置 | IoT 接入、视频接入、API 对接 |
| **日志** | 操作日志 | 审计追踪 |

### 3.3 企业角色权限

| 角色 | 说明 | 权限范围 |
|------|------|---------|
| **企业管理员** | 企业超级管理员 | 全部功能 + 成员管理 + Skill 配置 |
| **安全管理员** | 日常安全管理 | 数据看板 + Skill 操作 + 任务处理 |
| **操作员** | 一线操作人员 | AI 对话 + 巡查上报 + 查看通知 |

## 4. 多租户架构设计

### 4.1 租户隔离策略

```
┌─────────────────────────────────────────────────┐
│                  平台共享层                        │
│  · LLM 网关 (模型调用)                            │
│  · RAG 基础模型 (公共知识增强)                     │
│  · Agent 编排引擎 (Skill 调度)                    │
│  · Skill 注册表 (技能定义，不包含业务数据)          │
└────────────────────┬────────────────────────────┘
                     │
    ┌────────────────┼────────────────┐
    │                │                │
┌───▼────┐     ┌────▼───┐      ┌────▼───┐
│ 企业 A  │     │ 企业 B  │      │ 企业 C  │
│         │     │         │      │         │
│ DB_A    │     │ DB_B    │      │ DB_C    │
│ MinIO_A │     │ MinIO_B │      │ MinIO_C │
│ Milvus_A│     │ Milvus_B│      │ Milvus_C│
└─────────┘     └─────────┘      └─────────┘
```

**隔离级别**：
- **数据库**：同一 PostgreSQL 实例，按 `tenant_id` 行级隔离 + 索引
- **文件存储**：MinIO 按 bucket 或 prefix 隔离 (`/enterprises/{tenant_id}/`)
- **向量库**：Milvus 按 collection 或 partition 隔离
- **缓存**：Redis 按 key prefix 隔离 (`tenant:{tenant_id}:*`)

### 4.2 License 控制模型

```
License = {
    enterprise_id: UUID,
    type: "trial" | "standard" | "enterprise",
    skills: ["skill-a", "skill-b", ...],  // 授权 Skill 列表
    valid_from: datetime,
    valid_until: datetime,
    max_users: int,
    storage_quota: int,  // MB
    api_quota: int,      // 每日 API 调用上限
    is_offline: bool,    // 是否支持离线部署
    signature: str       // 防篡改签名
}
```

**过期策略**（参考 ai-admin-demo AGENTS.md）：
- 过期后允许：查看数据、下载报告、管理成员
- 过期后禁止：新增数据、调用 AI 接口、自动上报
- 提前 30 天开始提醒续费

## 5. 离线部署方案

### 5.1 适用场景

- 涉密/军工企业，数据不能出内网
- 政府/国企，有信创要求
- 网络条件较差，不稳定
- 企业对数据主权有严格要求

### 5.2 部署包内容

| 组件 | 说明 | 资源要求 |
|------|------|---------|
| 平台应用 | Docker 镜像 (后端 + 前端) | 2C 4G |
| PostgreSQL | 数据存储 | 2C 4G (推荐独立部署) |
| MinIO | 文件存储 | 按需 |
| Redis | 缓存 | 1C 2G |
| Milvus (可选) | 向量库 | 2C 4G (有 RAG 需求时) |
| Nginx | 反向代理 | 0.5C 1G |

### 5.3 离线部署流程

```
我方提供部署包 (Docker Compose / K8s Helm)
    │
    ▼
企业 IT 团队内部部署
    │
    ▼
我方远程指导配置 (初始数据导入、对接配置)
    │
    ▼
企业自运维 (我方提供技术支持)
    │
    ▼
定时同步 (可选)：Skill 版本更新、合规规则更新
```

### 5.4 信创适配

| 组件 | 信创替代方案 |
|------|-------------|
| CPU | x86 / ARM (鲲鹏/飞腾) |
| OS | 麒麟 V10 / 统信 UOS |
| 数据库 | 达梦 / 人大金仓 / openGauss |
| 容器 | Docker / 国产容器平台 |
